# Life is Bananas

Life is Bananas is a start-up that offers healthy fruit snacks. This projects aims to make hypothetical analyses, designs and tests with the goal to learn how each of these aspects are applied to a real world scenario.

This codebase is the result of three months of analysis and design to come up with this prototype of a solution.
